LEVEL DESIGN CASE STUDY · 01

时光遗迹

围绕“教学—挑战—奖励”建立10分钟第三人称线性箱庭体验，以时停、近战和平台跳跃构成复合玩法。

ROLE 关卡策划
ENGINE Unreal Engine 5
TYPE 3D动作冒险 / ARPG
DURATION 10分钟 · 4层
00 · OVERVIEW

体验目标

玩家以点亮时空水晶为目标，在清晰方向感下学习并组合核心能力。设计重点不是单点机关，而是把探索收集、平台解谜与战斗压力组织成有呼吸感的连续体验。

高压的战斗与平台解谜，和低压的探索收集交替出现，让玩家持续获得方向、挑战和回报。
01 · CORE MECHANICS

复合玩法框架

M01

时停机关

冻结旋转或往返平台，制造安全窗口；玩家先观察运动规律，再决定时停时机与通过路线。

M02

近战打断

把时停从移动平台延伸到战斗语境，用于控制威胁、创造近战输出窗口。

M03

平台跳跃

通过高低差、落点预览与空间地标降低迷失感，使操作挑战建立在明确意图之上。

02 · EXPERIENCE FLOW

教学—挑战—奖励

  1. 教学：在低风险环境中识别时空水晶与时停目标。
  2. 单项验证：用时停通过动态平台，建立“观察—冻结—行动”的操作循环。
  3. 复合挑战：将平台移动、敌人威胁与近战窗口叠加。
  4. 节奏释放：进入低压探索段，寻找时空石并重新建立方向感。
  5. 综合考验：在最终区域连续调用已学规则，完成收集闭环。
03 · DESIGN DECISIONS

关卡设计判断

空间先于装饰

用结构、视线与地标保证玩家能读懂下一步，而非依赖强制UI箭头。

机制逐步组合

先单独教学，再改变条件，最后与战斗叠加，避免一次性倾倒全部规则。

用节奏控制认知负荷

挑战后安排探索与奖励，让玩家消化新规则并准备进入下一轮压力。

04 · RULE SYSTEM

时停规则与机关组合

点亮第一颗时空水晶后解锁时停。按键5发射时光能量弹：机关冻结7秒，再次命中重置倒计时；敌人冻结7秒并受到20点伤害，同一时间只能冻结一名敌人。

3颗时空水晶7秒机关时停7秒敌人控制单目标限制死亡回溯至上一水晶
BASE

往返 / 旋转机关

玩家观察轴向运动和旋转轨迹，通过时停主动创造落脚点。

VARIANT

感应石联动

踩踏对应机关使感应石升起，再冻结石体，把两步操作组合为连续跳跃。

COLLECTION

时空石与屏障

互动机关附近藏有时空石；收集达到要求后解除屏障、开放电梯与下一层。

05 · FOUR-LAYER LAYOUT

四层递进结构

1F · 教学

建立基本规则

基础战斗、时停机关和视觉引导，让玩家形成“瞄准—冻结—行动”的操作模型。

2F · 组合

往返＋旋转

把独立机关组合成连续窗口，要求玩家在有限时间内规划下一次时停。

3F · 变种

感应石＋复杂跳跃

加入机关联动与更高垂直复杂度，同时利用POI保持方向感。

4F · 终局

战斗强化＋终极谜题

用掩体、远近敌人与时停控制交替组织战斗和解谜压力。
